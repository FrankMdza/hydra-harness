# Code of conduct

Be direct, be specific, and argue with records rather than with people. Disagreement about a
design decision goes into the ticket that made it. Harassment of any kind is not tolerated;
report it to the address in `NOTICE` and it will be handled privately.

This project follows the spirit of the Contributor Covenant, version 2.1
(https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
