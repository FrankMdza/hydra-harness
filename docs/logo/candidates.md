# Hydra logo candidates

Six drafts of a small mark, built from the three-headed HydraPet dragon. The human picks.
Each heading is the candidate's name, then the art in a fenced block, then one line on where it fits.
Names start with `line-`, `head-` or `splash-`, and that prefix sets the limits the test checks:
`line-` is one line, at most 24 columns, ASCII. `head-` is three lines, at most 32 columns, ASCII.
`splash-` is three to five lines, box and block characters allowed.

## line-eyes

```
(o)(o)(o) hydra
```

Fits: a status line or a shell prompt. Three round heads, 15 columns.

## line-fangs

```
>o >o >o ~ hydra
```

Fits: a prompt or a tab title. The heads face right like the sprite's jaws, 16 columns.

## head-necks

```
 <o  <o  <o
  \  |  /
   \_|_/  hydra
```

Fits: the cockpit header. Three necks join one body, the word sits at the base. 20 columns.

## head-crest

```
  __    __    __
 (o >) (o >) (o >)
   \___ | ___/   hydra
```

Fits: the cockpit header when there is room for bigger heads. 26 columns.
